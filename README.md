Aspiring applied mathematician with a focus on computational security and cryptography.

My background spans mathematics, computer science, and quantitative finance — a School Leaving Certificate in Science, Chartered Accountancy (CAP-I, Pass with Distinction), and a year of Computer Science coursework in Germany, all pointing toward the same conclusion: mathematics is where I do my strongest work, and where I want to build a career.

## Featured Project

**[CryptoLab](https://github.com/neeyamkafle/CryptoLab)** — A cryptography toolkit built from mathematical first principles: RSA, Diffie-Hellman, digital signatures, and classic attacks on misused RSA (common modulus, Fermat factorization, Håstad's broadcast attack), with no external crypto libraries. Also includes an honest account of trying, and failing, to build a hash function with a real avalanche effect, and what that taught me.
